# Backend 작업 지침

루트 `AGENTS.md`의 공통 지침과 함께 적용한다.

## 작업 범위

- 백엔드 작업에서는 `backend/` 디렉터리 안의 파일만 생성·수정·삭제한다.
- `frontend/`, `infra/`, 저장소 루트 등 `backend/` 밖의 파일은 임의로 변경하지 않는다. 코드 생성·포맷·테스트 등 명령 실행으로 발생하는 파일 변경에도 동일하게 적용한다.
- 다른 영역의 변경이 필요한 경우에는 필요한 내용과 이유를 사용자에게 보고하고, 해당 영역을 변경하라는 명시적인 지시를 받은 뒤 진행한다.
- 연동 확인을 위해 다른 영역의 파일을 읽을 수 있으나, 해당 영역의 기존 변경 사항을 수정하거나 되돌리지 않는다.
