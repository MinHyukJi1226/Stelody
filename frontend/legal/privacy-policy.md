# Stelody 개인정보처리방침

Stelody는 스텔라이브의 곡과 참여 멤버 정보를 찾아보고, 좋아하는 곡을 저장할 수 있는 비공식 팬 사이트입니다. 이 방침은 `stelody.vercel.app`에서 제공하는 Stelody 서비스가 어떤 개인정보를 어떻게 처리하고 이용자가 그 정보에 대해 어떤 권리를 행사할 수 있는지 설명합니다.

## 1. 처리하는 정보와 목적

곡과 멤버 정보는 Google 로그인 없이 볼 수 있습니다. 개인 보관함을 사용하면 Google 로그인으로 Stelody 계정에 접속합니다. Google 계정 비밀번호는 Google이 처리합니다. 회원은 YouTube로 플레이리스트를 내보낼 수 있습니다. Stelody는 회원이 Google에서 연결 권한을 허용한 경우에만 YouTube 계정에 접근합니다.

### 개인정보 처리 근거

- Google 로그인과 개인 보관함에 필요한 정보는 이용계약의 체결·이행을 위해 수집·이용합니다. 계정 탈퇴 정보는 이용자의 요청을 처리하는 데 사용합니다. [개인정보 보호법 제15조제1항제4호](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1022694549)
- 서비스 운영 기록과 백업은 장애 조사, 서비스 복구, 탈퇴 계정의 재생성 방지에 필요한 범위에서 사용합니다.
- YouTube 연결은 선택입니다. 회원이 Google에서 접근을 허용하면 부여받은 권한의 범위에서 연결을 유지하고, 내보내기를 요청한 목록을 처리합니다. 연결하지 않아도 즐겨찾기와 개인 플레이리스트를 이용할 수 있습니다.
- 이메일 문의는 이용자가 보낸 내용의 확인·처리·회신에 사용합니다. 열람, 정정·삭제, 처리정지 등 법령상 권리 행사에 필요한 정보는 해당 요청을 처리하는 데 사용합니다.

백엔드 앱은 이용자의 접속 IP와 전체 요청 URL을 일괄 기록하는 접근 로그를 사용하지 않습니다. 데이터베이스는 구조 변경 및 오류 SQL을 기록하며, 모든 쿼리를 기록하는 설정은 사용하지 않습니다.

## 2. 보유 기간과 파기

| 정보                     | 보유 기간 및 처리 방법                                                                                                                                                                                                                                                                                                               |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 회원 정보와 내 보관함    | 계정이 유지되는 동안 보관합니다. 목록을 삭제하거나 즐겨찾기를 해제하면 해당 항목을 삭제하고, 탈퇴가 완료되면 회원 정보와 개인 목록을 운영 데이터베이스에서 삭제합니다.                                                                                                                                                               |
| 로그인과 탈퇴 결과 확인  | 로그인 세션은 비활동 30분 또는 생성 후 최대 12시간이 지나면 만료됩니다. 일반 회원의 로그인 유지 자격은 로그인 시점부터 최대 30일간 유효합니다. 탈퇴 결과 조회 권한은 발급 후 24시간 동안 유효하며 만료 기록은 주기적으로 정리합니다.                                                                                                 |
| YouTube 연결과 내보내기  | 연결에 필요한 토큰은 암호화해 보관합니다. 내보내기 이력은 생성 후 30일이 지난 기록을 정기 작업에서 삭제합니다. 연결 해제 또는 권한 무효화가 확인되면 내보내기 기록을 삭제합니다. 연결 해제 시 Google에 권한 철회를 요청하고, 철회가 완료되면 남아 있는 토큰을 삭제합니다.                                                            |
| 백업과 탈퇴 기록         | 암호화 백업의 복원 유효기한은 최대 7일입니다. 실제 복구 가능 여부는 백업 파일이 남아 있는지에 따라 달라집니다. 백업에는 회원 정보와 개인 목록이 포함되며 인증 정보, 탈퇴 결과 조회 기록, YouTube 연결 토큰과 내보내기 이력은 제외합니다. 복원할 때에는 별도로 암호화한 탈퇴 기록을 대조해 탈퇴 계정이 다시 활성화되지 않도록 합니다. |
| 백엔드 운영 기록         | 현재 요금제 기준으로 운영자가 관리 화면에서 조회할 수 있는 로그 보관 기간은 Render 앱 로그 7일, Supabase DB 로그 1일입니다.                                                                                                                                                                                                          |
| 웹 호스팅·요청 중계 기록 | Vercel Runtime Logs의 현재 Hobby 요금제 보관 한도는 1시간입니다. CDN 요청 기록과 내부 보안·운영 기록의 보관은 Vercel의 일반 보관 정책을 따릅니다. Vercel은 처리 목적과 법적·계약상 의무 등에 필요한 기간 보관한 뒤 필요성이 없어진 정보는 삭제하거나 익명화하며, 즉시 삭제할 수 없는 백업은 안전하게 보관한다고 안내합니다.          |
| 이메일 문의              | 문의 처리 완료 후 90일간 보관한 뒤 메일함과 휴지통에서 삭제합니다.                                                                                                                                                                                                                                                                   |

Backblaze B2에서는 백업 파일을 업로드 후 1일이 지난 뒤 숨기고, 탈퇴 기록 파일은 업로드 후 8일이 지난 뒤 숨깁니다. 두 종류 모두 숨김 처리 후 1일이 지나면 영구 삭제 대상이 됩니다. 규칙은 일일 작업에서 적용되므로 실제 삭제 시점은 작업 실행 시각에 따라 달라집니다. [Backblaze B2 파일 삭제 규칙](https://www.backblaze.com/docs/en/cloud-storage-lifecycle-rules)

Render의 요청별 로그는 현재 사용하지 않습니다. [Render 로그 보관 안내](https://render.com/docs/logging#retention-period), [Supabase 로그 보관 안내](https://supabase.com/docs/guides/observability/logs)

Vercel의 Runtime Logs 보관 한도는 해당 로그에 적용됩니다. CDN 요청 기록, 내부 보안·운영 기록과 백업을 포함한 모든 기록의 최종 삭제 일수는 Vercel 공개 안내에 명시되어 있지 않습니다. [Vercel Runtime Logs 보관 한도](https://vercel.com/docs/logs/runtime#limits), [Vercel 정보 보관 정책](https://vercel.com/legal/privacy-notice#how-we-retain-your-information)

다른 법령에 따라 보존해야 하는 정보는 해당 법령의 보존 목적과 기간에 맞춰 다른 개인정보와 분리해 저장·관리하고, 기간이 지나면 복구할 수 없는 방법으로 삭제합니다. [개인정보 보호법 제21조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029334901)

## 3. 외부 서비스 이용과 국외 이전

Stelody는 Vercel에서 웹 화면을 제공하고, `stelody.vercel.app/api`로 들어오는 요청을 Render 백엔드로 전달합니다. Google 로그인과 YouTube API Services를 사용합니다.

### 서비스 운영을 위해 이용하는 업체

Stelody는 사이트 제공, API 처리, 데이터 저장 및 서비스 복구에 필요한 업무에 아래 서비스를 이용합니다. 이용계약의 체결·이행에 필요한 처리위탁이나 보관을 위해 개인정보를 국외로 이전하는 경우, 법령이 정한 요건에 따라 이 방침에서 이전 내역을 안내합니다. [개인정보 보호법 제28조의8제1항제3호](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1029332483)

### Google 로그인·YouTube 및 문의 메일

Google LLC는 Google 계정, YouTube, Gmail을 제공합니다. Google은 여러 국가에서 서버를 운영하며 거주 국가 밖에서 데이터를 처리할 수 있다고 안내합니다. 이용 건별 처리 국가는 Google의 공개 안내에서 확인할 수 없습니다.
