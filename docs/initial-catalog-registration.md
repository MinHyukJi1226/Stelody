# 전체 업로드 대조와 초기 곡 등록

2026-10-04 로컬 DB에 실제 멤버와 곡을 등록했다. 등록 명세는 [initial-catalog-20261004.json](../data/catalog/initial-catalog-20261004.json)에 있다. 앱 시작 시 실행하는 초기 데이터나 Flyway 마이그레이션으로 넣지 않았다.

## 확인 범위

- 사용자 제공 공식 그룹·개인 채널 11곳을 첫 업로드까지 탐색했다. 최신 50개만 처리한 기존 550개 후보에서 전체 과거 업로드로 범위를 확장했다.
- [공식 MUSIC](https://stellive.me/music)의 상세 286건을 모두 열어 연결된 YouTube ID와 가창자 표기를 대조했다. 공개 API로 285개 영상의 현재 상태와 음악 크레딧을 확인했다.
- 졸업 멤버 아이리 칸나의 공식 음악 채널과 공식 MUSIC에 연결된 `StelLive - Topic` 배급 음원 채널을 추가했다. 두 채널도 첫 업로드까지 탐색했다.
- 총 13채널의 `backfill_complete=true`를 확인했으며, 후보는 6,236개다. 게임·토크·홍보·쇼츠·방송 전체도 후보로 남을 수 있지만 공개 곡과는 다른 자료다.
- 제목에 `Cover`가 없는 OST, 방구석 뮤지컬, 자작곡, 공연곡도 확인했다. 음악 여부를 제목의 한 단어나 길이만으로 확정하지 않았다.

공식 MUSIC 286건 중 284건을 공개 곡에 대응시켰다. `Cookie` 영상은 공개 영상 조회 결과가 없어 등록하지 않았다. 리코의 39분 방종곡 플레이리스트는 10곡을 묶은 영상이므로 한 곡으로 등록하지 않았다. 두 항목의 출처와 사유는 명세의 `omittedOfficialMusic`에 있다.

| 공동 참여 | 70곡 |

[공식 TALENTS](https://stellive.me/talents)와 개인 프로필에서 활동 멤버의 이름·기수·생일·채널을 확인했다. 칸나는 공식 MUSIC의 졸업 표기와 공식 음악 채널로 등록했다. 확인하지 못한 졸업 멤버의 생일·기수는 비워 두었다. 예전 `@airikannach` 핸들은 현재 다른 이름과 새 개설일의 계정으로 연결되어 수집 채널로 등록하지 않았다. 공식 영상에 남아 있는 과거 채널 ID는 현재 조회되지 않았다.

기존 시험용 자료의 ID와 영상 연결, 먼저 등록한 32곡을 유지했다. 개인 목록·즐겨찾기의 참조를 삭제하거나 재생성하지 않았다.

곡별 제목과 `Vocal`, `Main Performance`, 공식 MUSIC의 가창자 표기로 참여자를 확인했다. 현재 채널 주인이나 공연 전체의 게스트 명단만으로 개별 곡 참여자를 추정하지 않았다. 네리사 레이븐크로프트·토도로키 하지메·VESPERBELL 요미·네코타 츠나·타요는 외부 아티스트로 연결했다.

커버는 OFFICIAL_COVER를 대표로 사용한다. 오리지널은 제작 크레딧이나 제목에서 확인한 공식 MV를 우선 사용하며, MV가 확인되지 않은 `Starry Way`, `Born To Run`, `Twinkle`, `To You, My Light`는 공식 음원을 사용한다. 어쿠스틱·리믹스와 별도 공연 녹음은 같은 원곡이라는 이유로 자동 합치지 않았다. 곡·영상별 조회수도 합산하지 않는다.

66초의 `SUPERPOWER (Arrange Ver.)`는 별도 편곡·가창·영상 제작 크레딧이 있는 공식 커버로 등록했다. 180초 이하라는 이유만으로 전체 곡을 Shorts로 처리하지 않았다. 원곡이 여러 개인 메들리·매시업은 원곡을 하나로 잘못 연결하지 않고 비워 두었다.

## 적용·검증

로컬 카탈로그 테이블을 백업한 뒤 스키마 소유자로 등록했다. 후보와 채널 잠금, 출처 채널 일치, 공개 상태·공개일·관측 유효기간, 영상 중복, 대표 영상 소속·종류, 확인된 참여자를 검사했다. 변경과 감사 기록은 같은 트랜잭션에 저장했다. 감사 기록은 회원을 임의로 지정하지 않고 `actor_id=null`, 실제 실행 역할을 `database_actor`에 기록했다.

등록 트랜잭션을 ROLLBACK으로 먼저 검사하고 실제 반영했다. 같은 명세를 다시 적용하는 검증에서 곡·영상·멤버·카탈로그 감사 기록의 중복 생성이 없었다. 수집 계정의 기존 권한 중 빠져 있던 분류 규칙 SELECT와 조회수 수집 시작일 열 UPDATE만 기존 권한 스크립트로 적용했다. 자동 공개 정책은 이 수동 등록 과정에서 활성화하지 않았다.

실행 중인 서버에 로그인 없이 요청하여 다음을 대조했다.

- 전체 공개 목록 페이지를 순회하여 360개 고유 곡 확인
- 커버 324곡, 오리지널 36곡, 공동 참여 70곡 필터
- 360곡 상세의 대표 YouTube ID·영상 종류·가창자·외부 참여자
- 11명 각각의 표시 곡 수와 실제 멤버별 목록 수 일치
- 활동 10명·졸업 1명 필터와 공식 채널 연결
- 일본어 별칭 `少女レイ`와 `불가행력` 검색
- 무작위 추천 20개와 결과 내 중복 없음

확인 경로: `/api/v1/members?status=ALL&size=50`, `/api/v1/songs?size=50`, `/api/v1/songs?collaboration=true&size=50`, `/api/v1/songs?type=ORIGINAL&size=50`. `hasNext=true`인 경우 응답의 `nextCursor`로 다음 페이지를 조회한다.

이번 변경은 등록 명세와 검수 기록이다. 백엔드 기능이나 프론트 화면을 추가하지 않았다. 작업용 등록 절차·검증 결과·백업은 로컬 임시 경로에 있으며, 운영 DB 적용 완료를 의미하지 않는다.

## 추가 후보에 대한 사용자 검수 결정

처음 추가 확인 대상으로 보고한 17개 중 `냉면🎵 - 타유 드라이브` 한 개를 등록했다. 나머지 16개는 사용자 검수 결정에 따라 이번 초기 카탈로그 등록에서 제외하고, 로컬 후보 상태를 IGNORED로 변경했다. 영상 ID·기존 확인 사유·제외 결정은 명세의 `excludedAdditionalVideos`에 기록했다. 후보 상태 변경과 감사 기록은 같은 트랜잭션에 저장했으며 기존 공개 곡을 삭제하지 않았다. `additionalReview`는 빈 배열이다.

- `냉면`은 공식 유니·타튜브 공동작업 채널 표기와 자막의 타요 호칭·함께 부르자는 대화, 공식 페이지에 표시된 명카드라이브 원곡 정보를 대조했다. 유니와 외부 가창자 타요의 공동 커버로 등록했다.
- 사용자는 노래 구간 3:26~7:05 제한 대신 원본 영상 전체 등록을 선택했다. 도입부 대화를 포함한 7분 27초 영상이며, 재생 구간 필드나 구간 재생 기능은 추가하지 않았다. 제목은 `냉면`, 원본 제목은 별칭으로 보존했다.
- 공식 배급 음원 10개는 이미 공개한 곡의 추가 업로드다. 이번에는 기존 곡에 연결하지 않았다.
- `여로`·`하나`·`최종화`의 라이브 클립 3개는 별도 녹음으로 이번 등록에서 제외했다.
- 유니 콘서트 스페셜 클립·마시로의 예전 패러디 영상·`메루메루…` 3개도 이번 등록에서 제외했다. 미확인 음악을 비음악으로 확정한 것은 아니다.

조회 가능한 지정 공식 채널의 과거 탐색과 공식 MUSIC 전체 대조는 완료했다. 이번에 별도로 보고한 17개에 대한 등록·제외 결정도 반영했다. 다만 모든 수집 후보의 판정을 끝냈거나 삭제·비공개 영상, 다른 채널에만 있는 음악까지 모두 확보했다는 뜻은 아니다.

미확인 원곡 아티스트, 프로필 이미지·데뷔일, 노래방 번호·음원 링크·검색 난이도는 비워 두거나 UNKNOWN/UNCHECKED를 유지한다. 과거 조회수는 만들어 넣지 않았다. 운영 적용 시에는 해당 DB의 후보와 기존 등록 자료를 먼저 대조해야 하며 로컬 `reviewId`를 운영 DB에 그대로 사용하지 않는다.
